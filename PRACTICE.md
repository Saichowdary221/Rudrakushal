# Learn with this project

1. HTML: change the main heading and add a fourth course card. Give its article
   a `data-course` attribute with searchable keywords.
2. CSS: change the accent color and the card border radius.
3. JavaScript: change the welcome message and display the number of button clicks.
4. DOM: add a button that hides or shows the About section.
5. Arrays and strings: add new course keywords and test the search.
6. Forms: add a required course-interest dropdown.
7. APIs (later): use a local HTTP server before experimenting with fetch requests.
   Fetching remote data also depends on that API's CORS policy.

## Manual checks

- The page opens without installation and all sections appear.
- Try JavaScript displays a welcome message.
- Dark mode updates colors and its button label.
- Search "CRM" shows only the Dynamics course; a nonsense term shows no results.
- Clearing search restores all three courses.
- On a narrow screen, Menu opens and closes; choosing a link closes it.
- The form rejects empty fields, invalid email, and a short or whitespace message.
- A valid form shows a clear demo confirmation without sending data.
- Tab through the page: links, buttons and fields have visible focus indicators.
